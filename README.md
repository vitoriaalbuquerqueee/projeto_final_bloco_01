   Sobre o Projeto

 Este sistema foi criado para gerenciar o fluxo de contratações de freelancers e temporários na minha empresa. O objetivo é usar a programação para trazer mais organização e praticidade para a rotina de quem lida com alto volume de profissionais.
O projeto aplica os conceitos de Programação Orientada a Objetos (POO) para facilitar o controle de escalas e registros de forma eficiente e escalável. 
Funcionalidades

 Cadastro ágil: Registro rápido dos serviços para otimizar o tempo. 
 Organização estruturada: Separação clara entre serviços temporários e freelancers. 
 Gestão simplificada: Foco em manter o controle de cada profissional de maneira centralizada. 📈
Estrutura Técnica
 Java: Linguagem utilizada para a lógica do sistema. ☕
 POO: Utilizada para modelar as classes de forma organizada. 
 Git/GitHub: Controle de versão para acompanhar a evolução do código. 📂
 
Como funciona
 ⁠Servico⁠ (Base): Contém os atributos fundamentais, como id, nome, preço, função e turno.
 ⁠ServicoExporadico⁠ & ⁠ServicoTemporario⁠: Classes especializadas para cada modalidade de trabalho.
 ⁠ServicoController⁠: Responsável pela lógica de cadastro e listagem dos serviços.
